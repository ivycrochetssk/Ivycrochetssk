# IvyCrochetssk — Handmade Crochet Website

Welcome to the official website for IvyCrochetssk! This is a beautiful, handcrafted website showcasing handmade crochet pieces, patterns, and beginner classes.

## 📝 Features

- **Shop**: Browse finished handmade pieces (shawls, wraps, blankets)
- **Patterns**: Download printable crochet patterns
- **Classes**: Learn about beginner crochet instruction
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Smooth Navigation**: Sticky header and smooth scroll behavior
- **Beautiful Color Palette**: Custom purple, peach, and cream aesthetic

## 🎨 Design

- **Fonts**: Fraunces (serif headlines) and Karla (body text) from Google Fonts
- **Color Scheme**:
  - Plum: #5c3a63
  - Purple: #8b5c96
  - Peach: #f0a98b
  - Cream: #fbf3ec

## 🚀 Deployment with GitHub Pages

This site is ready to deploy with GitHub Pages:

1. Go to repository **Settings**
2. Navigate to **Pages**
3. Set **Source** to "Deploy from a branch"
4. Select **main** branch and **/root** folder
5. Save

Your site will be live at: `https://ivycrochetssk.github.io/Ivycrochetssk/`

## 📦 What's Included

- `index.html` - Complete website with embedded styles and scripts
- `logo.png` - IvyCrochetssk badge logo (add your logo image with this filename)
- `README.md` - This file

## 📝 Customization

Update these placeholders in `index.html`:

- **Email**: `hello@ivycrochetssk.com` → your actual email
- **Instagram**: `https://instagram.com/ivycrochetssk` → your Instagram profile
- **Etsy Shop**: `https://etsy.com` → your Etsy shop link

## 📱 Mobile Responsive

The site uses modern CSS Grid and Flexbox with media queries for perfect rendering on all screen sizes.
